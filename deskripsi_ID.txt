[SIZE=5][COLOR=#A66A00][B]Tentang Plugin[/B][/COLOR][/SIZE]

OrbitSkills adalah plugin progression RPG untuk server Minecraft. Player tidak hanya naik level, tapi juga membangun karakter melalui Stat Point, Race, Clan, Class Rank, fragment, reward level, dan menu interaktif.

Setiap sistem punya peran sendiri:

[LIST]
[*][COLOR=#1E6F9F]Level[/COLOR] adalah progres utama player.
[*][COLOR=#237A4B]Stat Point[/COLOR] dipakai untuk meningkatkan damage, defense, HP, dan healing.
[*][COLOR=#5B3F99]Race[/COLOR] adalah asal/ras karakter player. Race bisa memberi stat, efek khusus, atau passive.
[*][COLOR=#9A5A00]Clan[/COLOR] adalah kelompok/bloodline/guild player. Clan fokus memberi bonus stat tanpa passive tambahan.
[*][COLOR=#A33A55]Class Rank[/COLOR] adalah kualitas tiap stat, dari F sampai SSS.
[*][COLOR=#1E6F9F]Fragment[/COLOR] dipakai untuk reroll Race, Clan, dan Class Rank.
[/LIST]


[SIZE=5][COLOR=#A66A00][B]Fitur Utama[/B][/COLOR][/SIZE]

[LIST]
[*]EXP dari banyak aktivitas seperti mob, mining, farming, fishing, combat, brewing, smelting, raid, dan lainnya.
[*]6 stat utama: Archery, Fighting, Power, Defense, Health, dan Alchemy.
[*]Race dengan rarity, chance, passive, dan fragment reroll.
[*]Clan sebagai bonus stat tambahan yang mudah dipahami.
[*]Class Rank F sampai SSS untuk membuat build player lebih unik.
[*]Auto reroll sampai rarity target tercapai.
[*]Guaranteed rarity agar player tidak sial tanpa batas.
[*]Scaled HP untuk membuat HP besar seperti 4000+ tetap terasa natural.
[*]Actionbar HP dan EXP progress.
[*]Leaderboard, profile, guide, level reward, stats, race, clan, dan class menu.
[*]PlaceholderAPI support untuk scoreboard, tab, dan menu lain.
[/LIST]


[SIZE=5][COLOR=#A66A00][B]Yang Membuat OrbitSkills Menarik[/B][/COLOR][/SIZE]

[LIST]
[*]Player tidak hanya grind EXP, tapi benar-benar membentuk karakter.
[*]Race memberi identitas karakter, Clan memberi arah bonus stat.
[*]Class Rank membuat build tidak hanya bergantung pada jumlah point.
[*]Fragment membuat reroll punya nilai dan bisa masuk ke ekonomi server.

[SIZE=5][COLOR=#A66A00][B]Command Utama[/B][/COLOR][/SIZE]

[LIST]
[*]/skills, /stats - Membuka menu stats.
[*]/level - Membuka menu level.
[*]/race - Membuka menu race.
[*]/clan - Membuka menu clan.
[*]/profile [player] - Menampilkan profile player.
[*]/os help - Bantuan admin.
[*]/os reload - Reload file plugin.
[*]/os scanall [fix] - Cek atau perbaiki SP player.
[*]/os give point|level|exp <player|*> <amount>
[*]/os give fragment <fragment> <player|*> <amount>
[*]/os set level|race|clan <player> <value>
[*]/os set class [player] <stat> <F-SSS>
[*]/os disable/enable <stats|class|race|clan|all>
[/LIST]


[SIZE=5][COLOR=#A66A00][B]Permission[/B][/COLOR][/SIZE]

[LIST]

[*]orbitskills.admin - Akses command admin.
[*]orbitskills.multiplier.2 / 3 / 4 - Tier EXP multiplier.
[/LIST]
